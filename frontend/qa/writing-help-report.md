# Проверка подсказок формы обращения

Изменения только frontend. Под темой добавлена короткая рекомендация;
под описанием — native details/summary, свёрнутый по умолчанию.
Тип suggestion использует существующее название «Предложение»; новых типов нет.
Для complaint/gratitude добавлены соответствующие вопросы.

80 тестов frontend прошли. Новая проверка подтверждает четыре набора вопросов,
перевод, сохранение открытого состояния и черновика, отсутствие подсказок
в аргументах создания и сворачивание блока при сбросе формы.

Firefox на отдельной базе в памяти:

- Раскрытие с клавиатуры, подсказка выбора типа до выбора.
- Четыре существующих типа: 4/3/4/3 вопроса, полные RU/KK-переводы.
- Тип и язык не меняют введённые тему/описание или выбранный PDF.
- Светлая/тёмная темы, 1280 и 390 px, без горизонтального переполнения.
- До отправки загрузок нет. В перехваченном POST создания только type,
  title, description с пользовательским текстом; отдельная прежняя загрузка
  вложения прошла, база содержит один PDF.
- Ошибок JavaScript не зарегистрировано. Скриншоты просмотрены.

Сценарий: writing-help-browser.mjs. Журнал: writing-help-results.json.
Скриншоты: writing-help-1280-light.png, writing-help-1280-dark.png,
writing-help-390-light.png, writing-help-390-dark.png.

Backend и API не изменялись. Основная база/реальные аккаунты не использовались.
Коммитов и push нет. Мобильный вид проверен viewport Firefox, не физическим
телефоном; остальные браузеры в этот прогон не входили.

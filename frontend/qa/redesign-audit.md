# UX/UI-редизайн «Голос команды»

## 1. Результат аудита

| Было | Решение |
|---|---|
| Создание обращения находилось в отдельной пустой панели | Основная кнопка рядом с заголовком, на телефоне на всю ширину |
| Между очередью, сотрудниками и деталями — разрозненные ссылки | Общая навигация по роли с текущим разделом |
| Статусы выглядели как цветной текст без выделения | Контрастные бейджи с точкой и полным названием статуса |
| Длинная форма создания сотрудника перед списком | Компактное раскрытие формы; список виден сразу |
| Результат создания с одноразовым паролем — обычный блок страницы | Модальное окно результата с очисткой секрета при закрытии/Escape |
| Рассмотрение и история шли длинной последовательностью | Основной контент и отдельная панель действий на широком экране |
| Нативный file input писал No files selected даже при выбранных карточках | Локализованная кнопка выбора, выбранные файлы показаны в существующих preview |
| Визуально равнозначные блоки и кнопки | Иерархия заголовков/данных/действий, опасные действия выделены отдельно |
| Длинные подписи действий ломались на телефоне | Широкие отдельные кнопки на узких экранах |

Новых бизнес-функций, типов обращений, API-маршрутов или библиотек не добавлено.

## 2. Дизайн-система

Светлая палитра: фон #F4F7FF, поверхность #FFFFFF, текст #172033,
акцент #405CF5. Тёмная: #101827 / #1C2940 / #EDF3FF / #8EA2FF.
Дополнительные цвета статусов, ошибок, фокуса, границ и поверхностей —
CSS-переменные в начале styles.css.

- Системная типографика без загрузки внешних шрифтов.
- Единые карточки, скругления, небольшие тени и интервалы.
- Кнопки и поля от 44–46 px, заголовки адаптируются к ширине.
- Статусы определяются текстом, цвет — дополнительный признак.
- Ошибки возле полей; общие сообщения имеют информационный/ошибочный/
  предупреждающий/успешный вариант.
- Небольшие hover-переходы. prefers-reduced-motion отключает переходы.
- Переключатель темы, сохранение и раннее применение до CSS сохранены.

## 3. Сохранённые сценарии

Вход/выход, обязательная смена пароля, кабинеты по роли, список/пагинация,
четыре типа обращений, создание, счётчики и рекомендации, выбор/предпросмотр/
удаление/загрузка/скачивание вложений, описание и история, очередь/фильтр/
статистика, рассмотрение и решение, создание/блокировка/активация сотрудников,
сброс пароля, обработка неизвестного результата и очистка секретов.

Сохранены существующие ID и обработчики. Native details/summary раскрывает
форму создания; исходный запрос не изменён. Native dialog показывает только
готовый одноразовый результат, а не блокирует интерфейс во время создания.

## 4. Проверка

- 81 frontend-тест прошёл. Добавлена проверка очистки пароля при нативном
  закрытии окна результата создания.
- Реальный Firefox: 320, 390, 768, 1280, 1920 px в light и dark.
  Проверены кабинет, форма/preview, админ-очередь, сотрудники и reset dialog.
- Горизонтального переполнения страницы нет; диалог полностью в viewport.
- Таблица очереди переключается в карточки, кнопки на телефоне остаются
  доступными, длинные имена/названия могут переноситься.
- Выбор файла через настоящий filechooser с клавиатуры → создание с PDF →
  просмотр и рассмотрение администратором → финальный комментарий — PASS.
- Создание сотрудника из раскрытия → одноразовый результат → Escape →
  пароль очищен — PASS; пароль не попадал в скриншоты/журналы.
- Активный раздел навигации единственный среди видимых ссылок.
- Контраст проверенных пар текста/фона, текста основной кнопки и четырёх
  бейджей: light минимум 5.16:1, dark минимум 6.12:1 (выше 4.5:1).
- Фокус виден; есть клавиатурный переход к содержимому; native summary/dialog
  доступны с клавиатуры. Уменьшение движения проверено по computed styles.
- Переводы RU/KK и сохранность текста/вложений при смене языка/темы проверены.
- Повторные сценарии theme-browser, password-reset-browser, audit-fixes-browser
  и attachments-browser проходят с новой структурой.

Скрипт полного прогона: redesign-browser.mjs, журнал: redesign-results.json.
Скриншоты: redesign-{width}-{theme}-{employee,form,admin,users,reset-dialog}.png.
Дополнительные снимки деталей, формы KK и экрана рассмотрения сохранены рядом.

## 5. Ограничения и безопасность проверки

Только localhost, искусственные аккаунты, SQLite в памяти и отдельное временное
хранилище. Основная база, backend, Cloudflare и серверные файлы не изменялись.
Внешние запросы заблокированы. Тестовые процессы закрыты, временные файлы удалены.
Коммитов и push нет.

Проверка мобильного вида — viewport Firefox, не физические устройства.
Chrome/Safari, нагрузка и публичное развёртывание в этот прогон не входили.
Проверки контраста/клавиатуры не равнозначны полной сертификации WCAG.

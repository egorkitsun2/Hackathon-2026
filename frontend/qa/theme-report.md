# Светлая и тёмная темы: проверка

Изменения только frontend, без новых production-библиотек и изменений backend.

## Реализация

- Солнце/луна в общей шапке: настоящая кнопка, доступная с клавиатуры,
  с переводимыми aria-label/title и состоянием aria-pressed.
- Выбор light/dark хранится только в localStorage (`team-voice-theme`).
  Данные форм, файлы, пароли и сессии там не сохраняются.
- До явного выбора используется prefers-color-scheme; системные изменения
  применяются автоматически. Некорректное значение хранилища игнорируется.
- theme-init.js выполняется до CSS и ставит data-theme до отрисовки;
  модуль theme.js управляет переключением, не перерисовывая формы.
- Палитры, статусы, ошибки, поля, кнопки, preview и backdrop модального окна
  используют CSS-переменные. Native controls используют color-scheme.

## Проверки

79 frontend-тестов прошли, включая новые проверки ранней инициализации,
сохранённого выбора, системной темы, переводов кнопки и отказа localStorage.

В настоящем Firefox на изолированном localhost и SQLite в памяти:

1. Старт с системной dark при искусственно задержанном app.js: корневой
   data-theme и computed color-scheme уже dark, фон #151a22 до запуска app.
2. Системное переключение без выбора; явная dark сохраняется при reload;
   сохранённая light имеет приоритет над системной dark.
3. Клавиатурное переключение, hover/focus, disabled/loading при задержанном
   входе: состояние запроса и введённый пароль не сбрасываются.
4. РУС/ҚАЗ: перевод кнопки меняется, заполненный текст и вложение сохраняются.
5. Вход, кабинет сотрудника, новое обращение с preview и ошибками, детали,
   таблица admin, статистика, список сотрудников и reset dialog просмотрены.
6. Обязательная смена пароля наследует тему; пароль в поле сохраняется при
   переключении. В снимке этого экрана поля оставлены пустыми.
7. На 320/390/1280 px нет горизонтального переполнения формы.
8. Проверенный контраст текста, подсказок, ошибок и четырёх статусов на тёмном
   inset-фоне — минимум 6.67:1 (выше 4.5:1). Это проверка указанных цветов,
   а не полный аудит соответствия WCAG всей страницы.

Журнал: theme-results.json. Скриншоты: 1280-theme-dark-login.png,
1280-theme-light-login.png, 1280-theme-dark-mobile-form.png,
1280-theme-dark-admin.png, 1280-theme-dark-modal.png и остальные theme-*.png.

Основная база и реальные аккаунты не использовались; тестовый сервер и браузер
закрыты, временные файлы удалены. Коммитов/push нет. Проверка мобильного вида
выполнена viewport настольного Firefox; реальные телефоны и другие браузеры
в этот прогон не входили.

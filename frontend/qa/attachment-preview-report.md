# Проверка предпросмотра вложений

Изменения только frontend, API-запросы и backend не изменялись.

## Пройденные проверки

- 76 тестов frontend: прежняя валидация/отправка, Unicode-счётчики и новые
  тесты выбора/удаления/повторного выбора/очистки превью и object URL.
- Firefox на отдельном localhost, SQLite в памяти, искусственный аккаунт
  и временная приватная папка. Основная база не использовалась.
- JPG, JPEG, PNG и WebP успешно декодированы браузером; PDF показан карточкой.
- Имя и размер файла отображаются как текст, без HTML-интерпретации.
- Повторный выбор добавляет файлы; четвёртый отклонён, выбранные не потеряны.
- Удаление одного файла с клавиатуры сохраняет остальные.
- До отправки не было ни одного POST вложений. После удаления JPG отправлены
  только PNG и PDF; база содержит ровно эти два имени.
- На РУС/ҚАЗ файлы сохраняются, подписи кнопок обновляются.
- Проверены ширины 320/390/1280 px, горизонтального переполнения нет.
- URL.createObjectURL используется только для изображений; URL не создаётся
  заново на каждый ввод текста. URL.revokeObjectURL проверен при удалении,
  очистке, уходе из формы и после отправки. Активных URL после этих действий — 0.
- При возврате в незавершённую форму изображения восстанавливаются новыми URL.
  Ошибки от уже удалённых старых изображений не затрагивают новые миниатюры.
- При ошибке декодирования показан текстовый fallback; серверная проверка
  содержимого файла остаётся прежней. Base64 в коде продукта не используется.

Сценарий: attachment-preview-browser.mjs. Журнал: preview-results.json.
Скриншоты: 1280-preview-desktop.png и 1280-preview-mobile-kk.png.
Тестовые сервер и Firefox закрыты, временное хранилище удалено.
Коммитов и push нет. Настоящие мобильные устройства не проверялись;
мобильная проверка выполнена сменой viewport Firefox.
